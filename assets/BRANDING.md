# Diver's Best Friend branding

The helmet inside the directional stratagem wheel is the primary DBF emblem. Use the approved artwork consistently across the README, project pages, release announcements, and community posts.

## Name and copy

- Project name: **Diver's Best Friend**.
- Short name: **DBF**.
- System name: **Automated Stratagem System (ASS)**. Keep ASS paired with its expansion in full branding placements.
- Short tagline: **Your stratagems. In the game.**
- Extended README tagline: **Your stratagems. In the game. No OCR. No Python. No AutoHotkey. Just a nice ASS.**
- Stable/canary labels and release numbers belong in surrounding page copy so the core artwork stays reusable.

## Artwork

- `dbf-logo-4x3.png`: approved compact 4:3 logo, with DBF, project name, and ASS expansion. Use for cards, thumbnails, and standalone branding.
- `banner-dbf.png`: 3:1 wide banner integrating the helmet/wheel emblem and DBF with the project name and ASS badge. Use at the top of the README and on wide project headers.
- `banner.png`, `banner.svg`, and `make_banner.py`: legacy banner and its generator. Retained for history; the script does not generate the new artwork.

Use the supplied PNG files without stretching, recoloring, or cropping away text. Keep clear space around the complete mark; approximately one arrow-width is a useful minimum. Use the wide banner in wide placements and the compact logo where there is enough height. Do not shrink the full lockup until its system-name line is unreadable.

## Palette and typography

Suggested companion UI/document colors, chosen to coordinate with the artwork:

| Role | Color |
| --- | --- |
| Background | Charcoal `#171B1C` |
| Accent | Signal yellow `#FFE033` |
| Primary text | Warm ivory `#FFF8DF` |
| Secondary text | Cool gray `#B8C1C4` |

Use bold angular display lettering in artwork and a plain readable sans serif for accompanying text. The generated wordmark is raster artwork, not a supplied font. Keep layouts simple: dark background, ivory title, yellow highlights, and restrained directional-wheel or grid details.

## Provenance

The approved compact logo and matching banner were made with the built-in image generation tool. The banner uses the approved logo as its identity reference and the previous banner as a format reference. Prompts are recorded in `dbf-logo-prompt.txt` and `banner-dbf-prompt.txt`.

These are independent fan-project graphics. Do not add official publisher marks or imply Arrowhead/Sony endorsement.
