Diver's Best Friend - Automated Stratagem System (ASS)
Revision 46 - Homecoming Update

Import DiversBestFriend-R46-BSL.zip into Arsenal, enable and deploy with Bingus Shared Loader. Close the game before replacing files and restart. Install one loader variant only.

Requires Mod Options Menu and Mod Bindings Menu v2+ / API 1. Dependencies are not bundled. MCM is optional and separately installed. Saved settings and bindings are retained.

Modes: Wedge Wheel (default), List Select and Native wheel. Configure Next, Previous and Confirm in MBM. Four equipped-stratagem hotkeys are unbound by default. Throw the beacon normally.

Cooldown dock/overview and timers consume native game state. Configure Appearance for timer positions, visibility and separated statuses.

Target Windows/Steam build 25480438. BSL remains restart-only. See RELEASE-r46.md for changes, compatibility and validation limits.
